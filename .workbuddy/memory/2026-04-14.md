### 路由守卫逻辑

```
登录流程：
  未登录 → /login
  已登录 → 获取用户信息 → is_superuser ?
    true → /admin
    false → /user

管理员路由 (/admin/*)：
  - 验证登录
  - 验证 is_superuser === true
  - 非超管 → 重定向到 /user

用户路由 (/user/*)：
  - 验证登录
  - 验证 is_superuser === false
  - 超管 → 重定向到 /admin
```

### 布局独立性

两套布局完全独立，互不影响：
- 修改 `_admin-layout.tsx` 的样式/结构 → 只影响管理员页面
- 修改 `_user-layout.tsx` 的样式/结构 → 只影响用户页面
- 可以分别将管理员布局改为上下排版，用户布局保持左右排版，或反之
