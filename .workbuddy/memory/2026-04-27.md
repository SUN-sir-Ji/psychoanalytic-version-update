## 答题提交后分析报告消失 Bug 修复

**问题**: 答完题显示"分析完成"后，页面中间内容区域空白，分析报告没有显示

**根因**: `handleTestSubmit` 中提交答案后，先把最后一条消息（"已提交测评..."）的 `isStreaming` 设为 `false`，然后 `onMessageEnd` 里用 `last?.isStreaming` 查找占位消息来填入报告内容——但此时最后一条消息已经不是 `isStreaming` 了，所以报告被丢弃

**修复**:
1. 提交答案后，额外添加一个新的 `{ role: "assistant", content: "", isStreaming: true }` 占位消息用于接收分析报告
2. `onMessageEnd` / `onError` / `catch` 中从后往前遍历找 `isStreaming` 的消息，而不是只看最后一条
3. 找到后一次性填入 `accumulated`（完整分析报告内容）

## Markdown 表格排版修复

**问题**: AI 返回的分析报告中"维度 → 表现特征"部分用 Tab 分隔，但没有渲染成表格，只是一堆文本挤在一起

**根因**:
1. 没有安装 `@tailwindcss/typography` 插件，`prose` 类完全不生效
2. AI 返回的是 Tab 分隔的伪表格（`\t`），不是标准 Markdown 表格（`|`）

**修复**:
1. 安装 `@tailwindcss/typography`，在 `index.css` 中添加 `@plugin "@tailwindcss/typography"`
2. 新增 `preprocessMarkdown()` 函数：检测连续 ≥2 行的 Tab 分隔内容，自动转为 `| 表头 |` + `| --- |` + `| 内容 |` 标准 Markdown 表格格式
3. `<ReactMarkdown>` 渲染前调用 `preprocessMarkdown(msg.content)` 预处理
