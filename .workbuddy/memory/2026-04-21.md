## 修复：对话发送消息卡死的 bug
- **问题**：输入文字点发送没反应，必须上传文件才能发
- **真正的根因**：发送按钮 `onClick={handleSend}` 直接绑定函数引用，React 将 MouseEvent 对象作为第一个参数传入 `extraFiles`，导致 `(extraFiles || []) is not iterable` 异常。而"开始分析"按钮调用 `handleSend(files)` 传的是真正的 File 数组，所以没问题
- **修复**：`onClick={handleSend}` → `onClick={() => handleSend()}`，用箭头函数包一层避免 Event 对象被传入
- **额外加固**：
  - `difyApi.ts`：fetch 调用加 try/catch，流读取循环加 catch，所有错误统一走 `callbacks.onError`
  - `ai-doctor.tsx`：handleSend 用 try/catch 包裹 sendMessageStream，加 `streamHandledEnd` 标志防重复重置
