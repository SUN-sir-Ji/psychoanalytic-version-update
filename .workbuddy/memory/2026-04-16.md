## 修复用户页"用户设置"点击退出登录的 bug（2026-04-17）

- 根因：`/settings` 挂在 `_admin-layout` 下，普通用户访问时被 beforeLoad 检测到非 superuser，redirect 到 `/user`，看起来像退出
- 修复方案：
  1. 新建 `_user-layout/settings.tsx`，路由 id 为 `/_user-layout/settings`，fullPath 为 `/user/settings`
  2. 更新 `routeTree.gen.ts` 注册新路由
  3. `User.tsx` 中根据 `user.is_superuser` 动态跳转：管理员 → `/settings`，普通用户 → `/user/settings`

## 注意

- `_user-layout/settings.tsx` 的路由文件 path 为 `/settings`，但因为挂在 `_user-layout` 下（path 为 `/user`），实际 fullPath 为 `/user/settings`
- `routeTree.gen.ts` 中 `fullPath` 字段需要手动写正确值 `/user/settings`，path 字段保持 `/settings`
